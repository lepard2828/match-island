# 版本紀錄

## v2.0.0 — 全向連鎖版

### 新增

- 八方向點選及拖曳交換，橫向、直向及兩種斜向連線消除。
- 手動三連產生 3×3 小炸彈，四連產生十字火箭，五連以上產生彩虹球。
- 每組獨立連線各獎勵一顆；相交線合併並優先最強道具。
- 點選道具後顯示爆破範圍，再次點選或使用引爆按鈕可發動。
- 六種雙道具組合；彩虹可與普通物品交換指定清除顏色。
- 棋盤內顯示道具標記、玩法圖例、本局生成及引爆數、最高連鎖統計。
- 新增「道具研究所」教學、第二版介紹與問題回報連結。

### 調整與修正

- 自動掉落連鎖只加分，不重新生成道具，避免道具膨脹。
- 全向三消目標改為 4,200 分，限時模式改為 6,000 分；原最高分保留。
- 保留群組消除及收納三消的原有規則與目標。
- 棋盤重新繪製後保留鍵盤焦點，重新開始會清除殘留拖曳狀態。
- 前端資源加入版本查詢參數，減少部署更新時混用舊程式的機會。
- 補充六種道具組合、斜向操作、指定顏色、爆破暫停等自動測試。

### 已知限制

- 分數保留在玩家瀏覽器，沒有全球排行榜或跨裝置同步。
- 未完成棋局不會儲存，重新整理會開始新局。
- 仍需真實 iOS Safari、Android Chrome 的長時間觸控驗收。
- 網站參考 Candy Crush 的玩法呈現方向，但不是官方作品或其遊戲複製版。

## v1.0.0 — 首次公開版

- 四種消除玩法與五款物品主題。
- 提示、洗牌、小槌子、音效、暫停與本機最高分。
- GitHub Pages 固定 HTTPS 網址，以及自動測試後發布。
